# Mxolisi Majenge — Personal Portfolio

A personal professional website built with plain HTML, CSS, and vanilla JavaScript — no build tools or frameworks required.

## Files
- `index.html` — all page content and structure
- `style.css` — styling, layout, animations
- `script.js` — nav scroll effect, mobile menu, scroll-reveal animations
- `assets/hero-bg.jpg` — hero section background image

## How to publish it for free

### Option 1: GitHub Pages (recommended)
1. Create a new GitHub repository, e.g. `portfolio` or `mxolisi-majenge`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repo (keep the same folder structure).
3. Go to **Settings → Pages**.
4. Under **Source**, select the `main` branch and `/ (root)` folder, then **Save**.
5. Your site will be live within a minute at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Netlify (drag-and-drop, also free)
1. Go to [app.netlify.com](https://app.netlify.com) and sign in.
2. Drag the whole project folder onto the Netlify dashboard.
3. Netlify instantly deploys it and gives you a live URL (you can later connect a custom domain for free).

## Customizing
- Update contact details, project descriptions, and social links directly in `index.html`.
- Colors and fonts are controlled via CSS variables at the top of `style.css` (`:root { ... }`), so you can re-theme the whole site by changing a few values.
- Replace `assets/hero-bg.jpg` with any other background image of the same aspect ratio to change the hero look.
